# 大肥鱼监工

### 给 AI 监督权，帮自己把任务做完。

大肥鱼监工是一个装在 [DeepSeek Harness（DSH）](https://github.com/deepseek-ai/deepseek-harness) 里的**自制力小助手**。你负责定目标，再安排 AI 盯着自己执行：看你正在做什么，在分心时提醒你，必要时直接关掉让你分心的窗口和应用。

它适合这样的时刻：明明知道该写论文、做项目、复习功课，却总想“再看五分钟”。这时，你可以提前把监督和强制干预的权限交给 AI，让认真定下的计划在想偷懒时也有人坚持执行。

**把任务说清楚，把监督交出去，让自己少一些耍赖的余地。**

## 它会怎样陪你完成任务？

**先约定，再开工。** 在 DSH 里告诉 AI，你要做什么、什么时候开始、什么时候结束、做到什么程度算完成。可以现在开始、预约一次，也可以约定每天或每周重复的任务。

**看实际行动，及时拉你回来。** 任务期间，大肥鱼会把你使用的窗口、页面内容、截图和活动变化交给 AI。写作中查资料，还是越刷越远，由了解任务约定的 AI 结合上下文判断；有疑问时，它可以先问你。

**提醒要能被看见，干预要真正有效。** AI 可以弹窗、播放声音，点击提醒就能回到对应监工会话。如果多次提醒仍然无效，它还可以最小化分心窗口，或强制关闭相关应用、窗口和浏览器标签。遇到保存提示或应用拒绝关闭，必要时会升级结束相关进程，让干预落实。

**做完再一起验收。** 回到原会话，和 AI 核对完成情况、解释遇到的问题，或讨论是否需要调整约定。电脑重启后，尚未结束的任务也会恢复。

> 强制关闭可能连带关闭同一应用的其他窗口或标签，并丢失未保存内容。启用监工前，请把允许 AI 如何提醒和干预，一起写进任务约定。

## 按你的需要选择任务严苛度

普通任务允许你在执行期间调整插件设置，也能从悬浮球手动结束。若这次确实想约束自己，就在创建时告诉 AI **设为严苛任务**：从预约开始，设置和手动结束入口会锁定。需要正当调整时，回到原监工会话与 AI 商量。

循环预约可以选择每天、每周指定星期，一直重复、到某一天为止，或总共执行若干次。悬浮球只显示一张循环卡片；普通循环可跳过本轮或结束整个循环。完整错过的轮次计入次数，不补跑；每轮到约定时间都会结束监督，延期要在到期前修改。

## 安装：一条命令，再点一次安装

### 先准备好

| 电脑 | 安装环境 |
| --- | --- |
| Windows | DSH Web、Node.js、Python 3、Edge |
| Linux | DSH Web、Node.js、Python 3、Chrome；推荐 Ubuntu 的 GNOME Wayland 桌面，使用 systemd |

Windows 请先装好 Python 3。后台其余依赖由安装器处理，安装时需要联网并完成系统授权。**浏览器无需额外安装采集扩展或 BrowserSkill。**

### 安装插件

用你平时登录电脑的用户打开终端，运行：

```bash
dsh plugin --profile web add https://github.com/RockingSisyphus/dsh-focus-supervisor/releases/latest/download/dsh-focus-supervisor.tgz
```

然后：

1. 打开或重启 DSH Web，找到大肥鱼，点击**安装后台**。
2. 按提示输入系统密码，或确认 Windows 的授权弹窗。
3. Linux 首次安装后，如果提示重新登录，注销并登录一次即可。

完成后，页面上就会出现陪你工作的鱼。后台服务会自动配置，日常使用无需反复授权。

也可以在 DSH 插件市场搜索“大肥鱼监工”；如果目录尚未同步，使用上面的命令安装。更新版本和安装包见 [Releases](https://github.com/RockingSisyphus/dsh-focus-supervisor/releases)。

## 第一次用，可以这样说

> 请你当我的监工，监督我今晚 8 点到 10 点写完论文引言初稿。开始前先和我确认完成标准。期间可以查论文，但如果我开始刷无关视频，请先弹窗提醒；多次提醒后仍不改，就最小化或关闭让我分心的窗口。到点后一起检查成果。

想建立习惯时也可以说：“接下来一个月，每周三和周日晚上 8 点到 10 点监督我复习，设为严苛任务。”

你也可以让它监督编程、学习、处理积压工作。**任务越具体，AI 越容易判断你是否在朝目标前进。**

点击大肥鱼悬浮球，可以查看任务、回到监工会话，或打开设置。提醒风格、任务要求都可以直接与 AI 商量。

## 按你的习惯调整

- **提醒方式**：希望温和询问，还是更严格地督促，把偏好告诉 AI。
- **采集频率与精度**：调整多久看一次桌面、截图尺寸，以及读取多少文字。
- **发给 AI 的信息量**：调整活动概览和详情的长度，在信息丰富程度与消耗之间选择。
- **任务严苛度**：按任务选择普通或严苛；严苛任务还有独立的监工要求提示词。

具体选项见 [采集设置说明](docs/sampling-settings.md)。

## 关于桌面信息

为了监督任务，AI 会看到插件采集的桌面内容。这些内容经 DSH 发送给**你配置的模型服务**，使用前请考虑工作资料是否适合交给该服务处理。

插件证据保存在本机，任务结束后按任务生命周期清理；聊天记录由 DSH 管理。采集主要关注当前可见的窗口和页面，部分应用的文字读取范围及平台问题见 [使用说明](docs/usage.md) 和 [当前问题](docs/known-issues.md)。
